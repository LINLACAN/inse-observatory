# InSe 薄片生长研究动态：公开阅读版

资料截至：2026-11-13。本部署自动更新尚未连接。

保留研究问题、实验设计、关键机制、性能与测试条件、局限、已核实的复现方法和与既有研究的差异；每张卡片保留原始来源与访问深度。

同行评议论文与预印本分开标记；已发表研究的早期预印本不重复计数。数值必须连同条件阅读，模型迁移率与不同器件的场效应迁移率不可直接排名。

本期无实质新增证据时保留“本期无重大进展”及其检索范围，不能据此断言整个领域没有进展。

- 已发现并核查2026年空间/地面InSe直接对照，不能写成整个InSe领域尚无空间制造证据。
- 该直接对照采用Bridgman块体生长后剥离；本轮检索未核实空间/地面InSe CVD直接对照，不能将块体结论等同CVD薄片结论。
- 2023年Materials Letters地面空间站模拟炉论文 DOI 10.1016/j.matlet.2023.133970 是地面预研：715°C、约30°C/cm、γ相R3m、腐蚀坑密度约10⁴ cm⁻²；它不是微重力实验。来源：https://www.sciencedirect.com/science/article/abs/pii/S0167577X23001556。
- 以上为选择性首轮文献核查，不是穷尽检索，也未据此断言2026-11某周绝无新论文。

本版仅公开阅读及本机收藏，不包含个人账号数据。原 Sites 周更不会自动同步到此部署。


## 2026-11-16 设计改版与维护

采用用户提供的 Opus 设计模板：全宽顶栏、点阵插图、论文库筛选、详情抽屉、三篇对比与手机布局。研究数据未改变，全部插图是艺术示意。

调整页面结构请编辑 index.html；调整颜色、字体、间距和手机布局请编辑 style.css；修改卡片、筛选、对比与展示逻辑请编辑 app.js；更新文献和期次请编辑 data.json。以上四个文件均为直接发布源文件，不需要运行改版归档中的一次性构建程序。可在 GitHub 网页直接修改，也可本地修改后提交，同步后检查 Pages 部署成功。

品牌数字使用内嵌 Doto；中文、英文正文和等宽标签改用系统字体，无字体 CDN 请求。完整字体许可保留供历史版本追溯。收藏沿用原有浏览器存储键，不会因本次改版主动清除。每周手动更新入口仍在本地资料根目录 00_每周手动更新.html，本次没有改变更新任务或接入模型。

## 2026-11-16 轻量化优化

点阵插图改为静态 Canvas，一幅图只保留一个绘制元素。首屏以外的插图接近可见区域时才绘制；移除 ResizeObserver 批量重绘和逐圆点动画。画布尺寸设上限，插图缓存最多 8 项。正文改用系统字体，仅保留 Doto 品牌字体；取消抽屉底栏模糊及全页平滑滚动。论文数据、筛选、收藏与更新规则保持不变。

资源版本号为 lite-20261116-1。修改 app.js 或 style.css 后，请继续更新 index.html 两处版本号。不同系统的正文字形可能略有差别。

## 2026-11-16 点阵动效与 Nothing 风格调整

点阵仍画在每幅插图一个 Canvas 上，圆点数据存在数组里，不生成 DOM。动效只在运动期间重绘，静止后停止：

- 插图出现时每个圆点各自放大浮现，带交错延迟。
- 鼠标悬停或键盘聚焦卡片（论文库卡片、主题卡片、收藏卡片；精读大卡片不翻转）时，插图圆点从指针位置开始逐点黑白翻转，瓷砖底色同步反转；加入对比的卡片保持反色。
- 首页和「追踪说明」页的主视觉有慢速扫描光和鼠标放大镜，只重绘光束和指针附近的格子，离开屏幕时暂停。
- 全页背景是一层固定的稀疏点阵（约 200 个点），载入时逐点出现，鼠标附近的点会放大。
- 页头 INSE 标志改为真实圆点，载入时逐点弹出，悬停时波动。
- Doto 数字进入视口时做一次翻牌式跳动；内容区块进入视口时淡入上移一次。

开启系统「减少动态效果」后，以上动画全部关闭。

样式参考 Nothing 官网：浅灰底色、悬浮圆角导航条、常规字重标题、10px 圆角瓷砖、方角按钮。去掉了页脚超大 INSE 和精读卡上的大编号，各页的期号、篇数大字缩小为普通数字。所有改动追加在 style.css 末尾的「Nothing-style refinement」段落。论文数据、筛选、收藏、对比与导出逻辑未改。

资源版本号现为 nothing-20261116-3。
