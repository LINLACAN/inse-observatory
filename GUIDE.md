# InSe 薄片生长研究动态：公开阅读版

资料截至：2026-11-13。本部署自动更新尚未连接。

保留研究问题、实验设计、关键机制、性能与测试条件、局限、已核实的复现方法和与既有研究的差异；每张卡片保留原始来源与访问深度。

同行评议论文与预印本分开标记；已发表研究的早期预印本不重复计数。数值必须连同条件阅读，模型迁移率与不同器件的场效应迁移率不可直接排名。

本期无实质新增证据时保留“本期无重大进展”及其检索范围，不能据此断言整个领域没有进展。

- 已发现并核查2026年空间/地面InSe直接对照，不能写成整个InSe领域尚无空间制造证据。
- 该直接对照采用Bridgman块体生长后剥离；本轮检索未核实空间/地面InSe CVD直接对照，不能将块体结论等同CVD薄片结论。
- 2023年Materials Letters地面空间站模拟炉论文 DOI 10.1016/j.matlet.2023.133970 是地面预研：715°C、约30°C/cm、γ相R3m、腐蚀坑密度约10⁴ cm⁻²；它不是微重力实验。来源：https://www.sciencedirect.com/science/article/abs/pii/S0167577X23001556。
- 以上为选择性首轮文献核查，不是穷尽检索，也未据此断言2026-11某周绝无新论文。

本版仅公开阅读及本机收藏，不包含个人账号数据。原 Sites 周更不会自动同步到此部署。


## 2026-11-16 设计改版与维护

采用用户提供的 Opus 设计模板：全宽顶栏、点阵插图、论文库筛选、详情抽屉、三篇对比与手机布局。研究数据未改变，全部插图是艺术示意。

调整页面结构请编辑 index.html；调整颜色、字体、间距和手机布局请编辑 style.css；修改卡片、筛选、对比与展示逻辑请编辑 app.js；更新文献和期次请编辑 data.json。以上四个文件均为直接发布源文件，不需要运行改版归档中的一次性构建程序。可在 GitHub 网页直接修改，也可本地修改后提交，同步后检查 Pages 部署成功。

字体已嵌入 style.css，无字体 CDN 请求。中文子集覆盖当前资料和页面文字；新增文字会使用系统中文字体补足。字体完整许可如下。收藏沿用原有浏览器存储键，不会因本次改版主动清除。每周手动更新入口仍在本地资料根目录 00_每周手动更新.html，本次没有改变更新任务或接入模型。
